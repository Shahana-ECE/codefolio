# CodeFolio – Developer Portfolio Builder

CodeFolio is a React-based web application that helps developers create their own professional portfolios easily.

## Features

- Enter personal details and professional information.
- Add skills and showcase technical knowledge.
- Add multiple projects with descriptions and GitHub links.
- View portfolio changes through a live preview.
- Choose between Modern and Classic portfolio templates.
- Download the generated portfolio.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## Project Objective

The main objective of CodeFolio is to provide developers with a simple and user-friendly platform to build and showcase their skills, projects, and professional information in one place.
